# 一起看书（书房第五栏）

上游：https://github.com/Shitsuten/anno-mcp

`client/` `server/` `data.example/` `README.md` 是**从上游原样搬过来的，一个字节都没改**
（`diff -r` 校验过）。将来上游更新，直接覆盖这几个目录就行，接入逻辑全在外面。

唯一一个不是上游的文件是 `server/package-lock.json`——`npm install` 生成的，
留着是为了装依赖可复现。覆盖上游时它不用管。

## 装 / 起

```bash
cd full-stack
./anno-setup.sh        # 一次就够：npm install、装 pymupdf/ebooklib、备好 /opt/marginalia
./run-with-anno.sh     # 以后每次用这个起（代替 ./run.sh）
```

## 接在哪

| 位置 | 干什么 |
|---|---|
| `app/anno.py` | 发阅读器前端 + 把 `/marginalia/api/*` 流式转给 Node，并守鉴权 |
| `app/main.py` | 挂路由；登录时多种一个 cookie |
| `app/claude.py` | `anno_mcp_servers()`，把六件工具挂给梁忱 |
| `static/index.html` | 书房第五栏 + `#annoPanel` 面板（iframe） |

## 三件反直觉但必须知道的事

**1. 前缀必须是 `/marginalia`，不能改。**
`client/anno.js:1` 写死了 `const API = '/marginalia/api'`。作者本来就是按反向代理设计的，
照着挂前端就一个字节不用改；换前缀就得去改人家源码。顺带好处：跟小窝自己的 `/api/*` 不撞车。

**2. MCP 端点是 `/mcp/sse`，不是 `/mcp`。**
上游 README 写的是「SSE (`/mcp`) 和 Streamable HTTP (`/mcp`)」——**是错的**。
`server.mjs` 只注册了 `/mcp/sse` 和 `/mcp/messages`，裸 `POST /mcp` 直接
`Cannot POST /mcp`。填错不会报错，只会让梁忱静默地一件工具都拿不到，
表现就是「一起看书」变成她一个人看。

**3. 四个写死的绝对路径。**
`server.mjs:19-22` 把这些写成了常量，上游 README 说能用环境变量改，也**是错的**：

```
/opt/marginalia/data          书和批注   ← 必须放持久卷
/opt/marginalia/uploads       上传的原件 ← 必须放持久卷
/opt/marginalia/extract_pdf.py
/opt/marginalia/extract_epub.py
```

因为不许改上游源码，`anno-setup.sh` 用软链把这四个位置备齐。
`ANNO_HOME` 指到持久卷，脚本会把 `/opt/marginalia` 软链过去。
**data 放错地方 = 容器一重建，她所有的批注就没了。**

## 鉴权

anno 自己**没有任何鉴权**，谁摸到就能读、能删。这道门由小窝守在 `app/anno.py`：
cookie 或 Bearer 认一个。iframe 发不出 `Authorization` 头，所以登录时会额外种一个
HttpOnly cookie（`app/main.py` 的 `login()`）。Node 只 listen `127.0.0.1`，外面进不来。

## 已验证

代理层（curl）：无凭证访问全 401，含 `DELETE 一本书`；cookie 和 Bearer 都放行；
静态文件白名单只放 `anno.css` / `anno.js`，`server.mjs`、`package.json`、`index.html`、
空字节、反斜杠穿越全部 404，响应里不含任何后端源码。

界面（Playwright，393×852）：书房五栏顺序 `记忆星图 / 日记 / 朋友圈 / 寄相思 / 一起看书`；
副标题读到真实书架「1 本」；点开后 iframe 加载 `/marginalia/`，里面 `document.title=Anno`，
书架列出《简单的激情（节选）》（说明转发通了）；夜间模式 / 搜索 / 字号 / 划线工具条 /
生词本 / 书签 / 批注面板七件功能全部在场；返回键能关；再打开不重建 iframe。

MCP（curl `/mcp/sse`）：`initialize` 握手成功，`tools/list` 返回六件——
`list_books` `read_pages` `read_annotations` `write_comment` `highlight_text` `get_progress`。

## 没验证的

- **真机**。以上都是云端 Chromium 里跑的。
- **她服务器上有没有 Node。** `requirements.txt` 的注释提到基础镜像是 `python:3.12-slim`，
  那个镜像里**没有 Node**。没有的话 `anno-setup.sh` 第一步就会停下来报错。
- **内存**。多一个 Node 进程 + pymupdf，常驻大概多几十到一百多 MiB。
  仓库注释里提到「队列 38 正在查小窝为什么涨到 189MiB」，这件事得心里有数。
- 上传 PDF/EPUB 的完整链路（要真文件 + pymupdf/ebooklib 装好才能测）。

## 面板上刻意没做的一件事

**没给 `#annoPanel` 挂 `bindSheetSwipeClose`。** 别的全屏面板都有横滑关闭，
这个故意不加：anno 最核心的功能是选中一句话画线，滑动关闭的手势会跟选字直接打架，
挂上去等于把划线砍了。退出走左上角返回键。

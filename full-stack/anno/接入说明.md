# 一起看书（书房第五栏）

上游：https://github.com/Shitsuten/anno-mcp

`client/` `server/` `data.example/` `README.md` 是**从上游原样搬过来的，一个字节都没改**
（`diff -r` 校验过）。将来上游更新，直接覆盖这几个目录就行，接入逻辑全在外面。

唯一一个不是上游的文件是 `server/package-lock.json`——`npm install` 生成的，
留着是为了装依赖可复现。覆盖上游时它不用管。

## 装 / 起

```bash
cd full-stack
./anno-setup.sh        # 一次就够：npm install、装 pymupdf/ebooklib、备好 /opt/marginalia
./run-with-anno.sh     # 以后每次用这个起（代替 ./run.sh）
```

## 接在哪

| 位置 | 干什么 |
|---|---|
| `app/anno.py` | 发阅读器前端 + 转发 `/marginalia/api/*` + 守鉴权 + 可选的对外 MCP |
| `app/main.py` | 挂路由；登录时多种一个 cookie |
| `app/claude.py` | `anno_mcp_servers()`，把六件工具挂给梁忱 |
| `static/index.html` | 书房第五栏 + `#annoPanel` 面板（iframe） |

## 两种用法，别搞混

**一、书房里的「一起看书」**（默认就有，不用配）
她在 iframe 里读，梁忱从小窝后端走 `127.0.0.1:3300/mcp/sse` 拿工具。
`run-with-anno.sh` 会自动设好 `ANNO_MCP_URL`。

**二、外部 MCP 客户端直连**（可选，默认关）
让 Claude Desktop / claude.ai 的连接器直接连她的书。开法：`.env` 里设
`ANNO_PUBLIC_MCP=1` 且 `ANNO_MCP_TOKEN=<一串随机字符串>`。
开了之后对外暴露 `/marginalia/mcp` 和根路径上那几个 OAuth 端点。

> 🔴 **两个条件必须同时满足才会真的挂载，只设开关不设令牌等于没开。**
> anno 的 `mcpAuthorized()` 在令牌为空时**直接返回 true**（`server.mjs:648`）——
> 空令牌挂到公网等于把她整个批注库对全世界敞开写。这条是 `app/anno.py` 硬拦的。

## 四件反直觉但必须知道的事

**1. 前缀必须是 `/marginalia`，不能改。**
两条独立证据：`client/anno.js:1` 写死了 `const API = '/marginalia/api'`；
`mcpResourceMetadata()` 返回的 resource 是 `${baseUrl}/marginalia/mcp`。
作者本来就是按反向代理设计的。照着挂，前端和 MCP 都不用动一个字节。
顺带好处：跟小窝自己的 `/api/*` 不撞车。

**2. MCP 端点是 `/mcp/sse`，不是 `/mcp`。**
上游 README 写的是「SSE (`/mcp`) 和 Streamable HTTP (`/mcp`)」——**是错的**。
`server.mjs` 只注册了 `/mcp/sse` 和 `/mcp/messages`，裸 `POST /mcp` 直接
`Cannot POST /mcp`。填错不会报错，只会让梁忱静默地一件工具都拿不到。

**3. 四个写死的绝对路径。** 上游 README 说能用环境变量改，也**是错的**，
`server.mjs:19-22` 是常量：

```
/opt/marginalia/data          书和批注   ← 必须放持久卷
/opt/marginalia/uploads       上传的原件 ← 必须放持久卷
/opt/marginalia/extract_pdf.py
/opt/marginalia/extract_epub.py
```

不许改上游源码，所以 `anno-setup.sh` 用软链把这四个位置备齐。
`ANNO_HOME` 指到持久卷，脚本会把 `/opt/marginalia` 软链过去。
**data 放错地方 = 容器一重建，她所有的批注就没了。**

**4. iframe 里 `env(safe-area-inset-*)` 恒为 0。**
安全区只对顶层文档生效。anno 自己的 CSS **是**处理了底部安全区的
（它的底栏有 `env(safe-area-inset-bottom)`），但嵌进来之后那套全失效，
底栏会被 home 指示条压住。所以这段留白由外面补：
`#annoPanel .fsheet-body{padding-bottom:env(safe-area-inset-bottom,34px)}`。

同理，iframe 默认没有剪贴板权限，anno 选中文字后的「复制」按钮走
`navigator.clipboard.writeText()`（`anno.js:704`），**不给
`allow="clipboard-write"` 会静默失败**。

## 鉴权

anno 自己对 `/api` **没有任何鉴权**，谁摸到就能读、能删。这道门由小窝守在
`app/anno.py`：cookie 或 Bearer 认一个。iframe 发不出 `Authorization` 头，
所以登录时会额外种一个 HttpOnly cookie（`app/main.py` 的 `login()`）。
Node 只 listen `127.0.0.1`，外面进不来。

## 上游本身的几个毛病（不是我们砍的，也没去改）

- **PDF 目录提取根本没实现。** `extract_pdf.py` 里没有 `toc` 这个词，
  虽然 `server.mjs` 会去读 `parsed.toc`。所以 PDF 传进来 `toc_count` 永远是 0。
  EPUB 那边实现了，但要求目录标题跟某个正文段落**精确匹配**才保留
  （`extract_epub.py:117` 会把匹配不上的全过滤掉）——章节名写在 `<h1>` 里的
  EPUB 基本都会得到空目录。
- **中文文件名传 `.txt` 会乱码。** multer 用 latin1 解 `originalname`，
  `测试书.txt` 变成 `æµè¯ä¹¦`。PDF/EPUB 不受影响（标题从文件元数据取）。
  **补救：阅读器里有 Rename 按钮**（书的右键菜单和书详情页都有），点一下改掉就行。
  为这个去改上游源码不值得。
- **正文高度重复的 PDF 会被提取成空的。** `extract_pdf.py` 有个页眉页脚检测：
  出现在 >40% 页面上的行会被当页眉删掉。测试时我用重复段落造了个 PDF，
  结果整本被清空（0 段 0 页）。真实书籍不会触发，但值得知道。

## 已验证

**上传（经小窝代理，不是直连）**：`.txt` 28 段 / `.pdf` 32 段 4 页 / `.epub` 28 段，
三种格式全通。pymupdf 和 ebooklib 都真装了跑的。

**读**：翻页、全文搜索（28 条命中）、目录接口、书架列表、删除书。

**写（七件，一件不少）**：她写批注、他写批注、**他划线（文本级高亮，anno 的招牌功能）**、
书签、生词本、阅读进度、重命名。读回来 3 条批注，`reader/comment`、
`claude/comment`、`claude/highlight` 三种身份和类型分得清清楚楚——
两支笔是分开存的，这正是「一起看书」跟普通阅读器的区别。

**鉴权**：无凭证访问全 401（含 `DELETE 一本书`）；cookie 和 Bearer 都放行；
静态白名单只放 `anno.css`/`anno.js`，`server.mjs`、`package.json`、`index.html`、
空字节、反斜杠穿越全部 404，响应里不含任何后端源码。

**对外 MCP 的安全默认值**（三个实例对比跑的）：
什么都不设 → 那组路由 GET 全部 404，整组不存在；
`ANNO_PUBLIC_MCP=1` 但令牌为空 → 仍然 404，硬拦住；
开关和令牌都给 → 挂上，不带令牌被 anno 拦成 401，带对令牌拿到六件工具，
OAuth 发现文档返回的对外地址拼对了（说明 `X-Forwarded-*` 转发生效）。
三种配置下阅读器本身都照常要登录。

**界面**（Playwright 393×852，13 项全过）：书房五栏顺序
`记忆星图 / 日记 / 朋友圈 / 寄相思 / 一起看书`；副标题从真实书架读出本数；
iframe 加载 `/marginalia/`，`document.title=Anno`；夜间模式 / 搜索 / 字号 /
划线工具条 / 生词本 / 书签 / 批注面板七件全在；`allow="clipboard-write"` 在；
安全区规则在且优先级压得过 `.fsheet-body-flush{padding:0}`；
返回键能关；再打开不重建 iframe。

**手势冲突**：查过了，`#drawerGesture{display:none!important}` 全局禁用，
而且就算开着也是 `z-index:30`，在 `.fsheet` 的 `z-index:82` 底下。不冲突。

## 没验证的

- **真机**。以上都是云端 Chromium 里跑的。这一条不要当成小事——
  导航栏那个 bug 就是栽在「云端说没问题、真机是坏的」上。
- **她服务器上有没有 Node。** `requirements.txt` 的注释提到基础镜像是
  `python:3.12-slim`，**那个镜像里没有 Node**。没有的话 `anno-setup.sh`
  第一步就会停下来报错。
- **内存**。多一个 Node 进程 + pymupdf，常驻大概多几十到一百多 MiB。
  仓库注释里提到「队列 38 正在查小窝为什么涨到 189MiB」，这件事得心里有数。
- **梁忱真的动手批注一次**。MCP 握手和 `tools/list` 验过了，但没让他真的
  调一次 `highlight_text` 写进去（那要跑起完整的后端）。

## 面板上刻意没做的一件事

**没给 `#annoPanel` 挂 `bindSheetSwipeClose`。** 别的全屏面板都有横滑关闭，
这个故意不加：anno 最核心的功能是选中一句话画线，滑动关闭的手势会跟选字直接打架，
挂上去等于把划线砍了。退出走左上角返回键。

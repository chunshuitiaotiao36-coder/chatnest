# 在这个仓库干活的规矩

给所有接手的 agent（Claude Code / Codex / 别的）。下面每一条都是拿时间或钱换来的，
不是风格偏好。

## 1. 不许砍功能。这条排第一。

做琴房那次，**一周的额度耗完了，东西也没做好**——原因就是中途「灵机一动」
把范围缩小了：这个先不做、那个简化一下、这块后面再说。结果是每一轮都在做半成品，
每一轮都要重来。

所以：

- 需求里写了的，**全做**。做不完就说「我做到哪儿、剩下什么」，
  **不要自己决定哪些不重要**。
- 接开源项目进来时，**默认是整个接进来**。上游有的能力少一样，都算砍。
  真有做不了的（依赖不到位、上游本身就没实现），**明说是哪一条、为什么**，
  写进说明的「没验证的 / 没做的」一节。
- **「先不做」「暂时简化」「后续再补」这类判断一律不许自己下。** 拿不准就做。
- 任何「我觉得她其实不需要这个」的念头，都是错的。她需要的东西她写了。

## 2. 真机为准。云端浏览器会骗你。

底部导航栏那个 bug 修了八次没修好，一半原因是云端 headless Chromium 三次给出
与真机相反的结论。实测差异：

- `env(safe-area-inset-*)` 在云端解析成 **0**，真机是 34/50。
  `--tabbar-h` 因此量出 53px 而不是 86px。
- 云端**没有软键盘**，凡是键盘参与的机制在那边 100% 复现不出来。
- Blink 会在元素转为 `visibility:hidden` 时自动 blur 焦点，**WebKit 不一定**。

云端只能用来验证「我没把别的弄坏」。**不能用来验证「这个 bug 修好了」。**
她真机上说坏，那就是坏的。

## 3. fallback 的意义是不崩，不是不吭声。

仓库里 `push.py` `piano.py` `bgline.py` 都写着这句。反面教材：pro 过期那一个多
星期，三条后台线每次都抛异常、被 `except Exception` 吞进日志、循环照转，
她一条消息一封信都没收到——**而日志没有人看**。

所以：静默降级等于故障。降级了要有人能看见——日志之外，还要有她能看见的通道。

## 4. 状态必须落持久卷，而且要在启动时建。

`/data` 是持久卷，`/app` 是镜像。**构建期在 `/data` 下建的目录和文件，
会被运行时挂上来的卷整个盖掉**——所以 `mkdir` 和软链要写在
`docker-entrypoint.sh` 里，不是 `Dockerfile` 里。

软链尤其小心：`ln -sfn A B` 在 B 已经是**真目录**时，会在 B **里面**建一个嵌套
软链而不是替换它。后果是服务继续读老目录、她的数据看起来「消失」，
而且一个字的报错都没有。见 `docker-entrypoint.sh` 的 `link_opt()`。

## 5. 不许硬编码模型 ID。

她线路上的 id 带渠道前缀（`[k-特惠]claude-sonnet-4-6`），裸 id 在
`available_models()` 里查不到，`stream_chat` 第一行就 raise，然后被外面的
`except Exception` 吞掉——功能静默哑掉，日志里一个字都没有。
这个坑在 `_summary_model`、`telegram._pick_model`、`background_model` 上各踩过一次。

## 6. 多个 agent 同时在这个仓库里干活。

`full-stack/static/index.html` 是所有人都要改的那个文件（7000+ 行）。
动它之前**先 `git pull`**，别在旧版上改完硬推。
不确定别人在不在改，就先问，或者改在分支上。

## 7. 前端浮层规则

所有遮罩 / overlay 必须由状态驱动显隐（display / visibility / pointer-events）。
禁止常驻透明层依赖 z-index 压制。每次新增浮层后，必须用元素拾取器验证其关闭状态
不拦截页面点击。

## 8. 注释是这个仓库的资产，不是噪音。

带 🔴 的注释记的都是踩过的坑和它的代价。**不要删，不要「精简」。**
改到某一段时先读它上面那段红字——多半你正要犯的错就写在那儿。
自己踩到新坑，也照这个格式留下来。

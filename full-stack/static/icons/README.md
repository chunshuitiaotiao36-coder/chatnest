# 主屏图标

**不用往这个目录塞文件。** 在 app 里换：

> 我 → 主题与背景 → 主屏图标 → 选择图片

上传的图存在服务端 `/data/icons/`（持久卷，重新部署不会冲掉），
前端自动切成 180 / 192 / 512 三个尺寸并转成 PNG。

这个目录只是兜底：如果哪天想把图标钉进版本库，把 `nepeta-180.png`
放进来，`/data` 里没有的时候会回落到这里。

## 换完图标要重新添加到主屏幕

iOS 在你「添加到主屏幕」的那一刻就把图标复制走了，之后**不会**自己更新。
换了图标必须：删掉主屏上那个 → 重新添加。

## 三条不要

- **不要自己加圆角。** iOS 装到主屏时自己切一次，自带圆角会被切两遍，
  边上留一圈白边。前端只做「居中裁方 + 缩放」，不动圆角。
- **不要指望透明。** 透明区在 iOS 上会变黑，前端会先铺一层白底。
- **不要用 SVG。** iOS 的 `apple-touch-icon` **不支持 SVG**，会被静默忽略，
  然后 iOS 拿站名首字母画个方块顶上——主屏那个丑 N 就是这么来的。
  接口只收 `image/png`。

## 不要引 manifest

`index.html` 的 head 里**永远不要**加 `link rel=manifest`：iOS 一看到它就
退回实心状态栏，`black-translucent` 的沉浸式效果当场作废。

主屏图标不需要它——iOS 只认 `apple-touch-icon`，manifest 里的 `icons`
数组是给 Android / Chrome 看的。
